주차별 훈련 현황

러닝과 휴식을 구분합니다. 각 구간의 일수가 달라 총거리만으로 비교하지 마세요. 목표 속도 구간은 5:41/km ±10초 기준이며 완주 확률이 아닙니다.

거리: 목표 범위의 하한 기준 · 페이스: 목표 범위에 가까울수록 100% (과속 보상 없음). 구간 훈련은 전체 평균과 직접 비교하지 않습니다.

추가 훈련 기록
다른 기기의 기록이 반영되었습니다. 입력 화면을 새 값으로 다시 표시할 수 있습니다.

RPE는 달린 뒤 스스로 평가하세요: 1~2 매우 가벼움 · 3~4 편안함 · 5~6 제법 힘듦 · 7~8 힘듦 · 9~10 매우 힘듦~최대 노력. 심박수·케이던스를 옮기는 칸이 아닙니다. 모바일에서는 일지 상단을 좌우로 쓸어 날짜를 이동할 수 있습니다.

계정 · 클라우드 동기화

로그아웃 · 로컬 모드

Supabase 연결 설정

Publishable 또는 기존 anon 키만 사용합니다. Secret·service_role 키는 입력하지 마세요. 이 설정은 각 기기에서 한 번 입력합니다.

입력은 기기에 먼저 저장한 뒤 자동 전송합니다. 다른 기기 변경은 창으로 돌아올 때 또는 ‘지금 동기화’로 확인합니다. 기존 기록 가져오기는 로그인 전 기록을 계정에 병합합니다.

연결 설정 전에는 기존 로컬 저장으로 작동합니다.

기록 보관함

기존 저장 키와 모든 날짜의 기록을 유지합니다. 새 파일은 브라우저에 따라 별도 저장 공간을 사용하므로 처음에는 기존 파일에서 백업을 옮겨 주세요.

Supabase 설정과 로그인 후 기기 간 동기화할 수 있습니다. JSON 백업도 계속 보관하세요. 기존 키의 초기 스냅샷은 별도로 보존하며 원본·기간 밖 기록도 삭제하지 않습니다.

오프라인 단일 HTML · 입력 즉시 기기 저장 · 스트라이드: 20~25초 가속 후 60~90초 회복 · 쿨다운: 가벼운 걷기 / 조깅

기존 기록을 새 플래너로 옮기기

기존 HTML을 열고 브라우저 개발자 도구의 콘솔에서 아래 코드를 실행하면 JSON 백업이 다운로드됩니다. 이 파일을 새 플래너의 ‘백업 가져오기’로 불러오세요.
